# Jeevan Biju — AI / Computer Vision Engineer

🌐 **Live Website**: [https://portfolio-self-ten-19.vercel.app/](https://portfolio-self-ten-19.vercel.app/)

Personal portfolio website for **Jeevan Biju**, an AI & Computer Vision Engineer building real-time, GPU-accelerated, and edge-deployed visual intelligence systems.

---

## ⚡ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide Icons
- **Deployment**: Vercel
- **Design System**: Instrumented Editorial field-log aesthetic with custom interactive cursor & GPU pipeline schematics

---

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/JeevanBiju/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
